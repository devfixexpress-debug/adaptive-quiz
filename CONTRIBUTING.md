# Contribución

## Flujo
1. Crear/seleccionar un Issue.
2. Crear branch desde `develop`.
3. Implementar con pruebas.
4. Commits Conventional Commits.
5. Abrir Pull Request.
6. CI verde.
7. Merge.

## Branches
- `main`: releases.
- `develop`: integración.
- `feature/<issue>-<descripcion>`
- `fix/<issue>-<descripcion>`
- `docs/<issue>-<descripcion>`
- `test/<issue>-<descripcion>`

## Commits
Ejemplos:
- `feat(adaptation): calcular contexto de aprendizaje (#18)`
- `test(adaptation): cubrir regla de rendimiento alto (#19)`
- `docs(data): actualizar diccionario semántico (#20)`
