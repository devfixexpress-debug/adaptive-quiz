# Alcance

## Incluido en Taller 001
- Aplicación Android.
- Banco de ejercicios de opción única.
- Temas y tres dificultades: básico, intermedio y avanzado.
- Registro de intentos.
- Medición de aciertos, errores, tiempo y rachas.
- Ventana móvil de rendimiento.
- Motor de reglas.
- Subir/mantener/bajar dificultad.
- Activar pista como acción adaptativa.
- Monitor adaptativo observable.
- Backend REST y persistencia PostgreSQL.
- Historial de eventos adaptativos.
- README, Git, CI, documentación y pruebas.

## Fuera del núcleo obligatorio
- LLM para decidir la adaptación.
- Generación automática de preguntas con IA.
- Tutor conversacional.
- Evaluación semántica de respuestas abiertas.
- Integración real con VAEF Learning.
- Multi-tenant.
- Monetización.

## Restricción arquitectónica
El núcleo del Taller debe funcionar aun cuando la IA esté deshabilitada o no disponible.
