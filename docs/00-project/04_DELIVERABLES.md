# Entregables

## Exigidos por Taller 001
1. Repositorio Git.
2. Código fuente completo.
3. Proyecto ejecutable.
4. README con instrucciones.
5. Dependencias declaradas.
6. Historial de commits.
7. Documento técnico máximo 2 páginas.
8. Demostración en tiempo real.
9. Capacidad de explicar/modificar código durante sustentación.
