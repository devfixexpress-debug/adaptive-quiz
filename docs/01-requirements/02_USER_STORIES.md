# Historias de Usuario

## HU-001 — Resolver ejercicio
Como estudiante quiero resolver un ejercicio para practicar un tema.

Relacionado: RF-002, RF-003, RF-004, RF-005.

## HU-002 — Registrar mi desempeño
Como estudiante quiero que la aplicación registre automáticamente mi desempeño para no
tener que configurar manualmente mi nivel.

Relacionado: RF-006, RA-001, RA-002.

## HU-003 — Recibir dificultad adaptada
Como estudiante quiero que el sistema ajuste la dificultad según mi rendimiento para recibir
ejercicios acordes con mi desempeño.

Relacionado: RA-003, RA-004, RA-005, RA-006, RA-007.

## HU-004 — Recibir ayuda adaptativa
Como estudiante con dificultades quiero que el sistema habilite una pista automáticamente.

Relacionado: RA-008.

## HU-005 — Ver por qué cambió mi nivel
Como estudiante o revisor quiero ver el contexto y la decisión adaptativa para comprender el
comportamiento del sistema.

Relacionado: RA-010, RA-011, RA-012, RNF-004, RNF-008.

## HU-006 — Consultar progreso
Como estudiante quiero consultar mi avance por tema.

Relacionado: RF-007.

## HU-007 — Revisar trazabilidad técnica
Como docente quiero identificar dónde se captura, procesa, decide y adapta para poder revisar
la solución durante la sustentación.

Relacionado: RNF-001, RNF-002.
