# Problema y Oportunidad

## Problema
Una secuencia fija de ejercicios no representa la diversidad del rendimiento real de los
estudiantes. El usuario debe adaptarse al sistema en lugar de que el sistema responda a su
contexto.

## Oportunidad
Convertir la evidencia operativa de cada intento en un contexto de aprendizaje y usarlo para
seleccionar dinámicamente la siguiente experiencia.

## Hipótesis
Si el sistema usa precisión, tiempo y consistencia reciente para decidir dificultad y ayudas,
entonces podrá demostrar comportamiento adaptativo real sin intervención manual.

## Evidencia observable
- contexto calculado;
- regla seleccionada;
- decisión;
- dificultad anterior;
- dificultad nueva;
- siguiente ejercicio.
