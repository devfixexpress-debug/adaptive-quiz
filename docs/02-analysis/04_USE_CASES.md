# Casos de Uso

## CU-001 Iniciar práctica
Actor: Estudiante.
Resultado: sesión de práctica activa.

## CU-002 Obtener siguiente ejercicio
El sistema usa tema y dificultad actual para seleccionar un ejercicio aplicable.

## CU-003 Responder ejercicio
El estudiante responde; el sistema registra tiempos y califica.

## CU-004 Evaluar contexto adaptativo
El sistema toma los últimos intentos y calcula métricas.

## CU-005 Aplicar adaptación
El motor selecciona regla y genera acciones.

## CU-006 Consultar progreso
El estudiante consulta estado agregado por tema.

## CU-007 Revisar monitor adaptativo
El estudiante/docente observa contexto, decisión y adaptación.

## CU-008 Mantener configuración
Administrador mantiene parámetros, políticas y reglas.
