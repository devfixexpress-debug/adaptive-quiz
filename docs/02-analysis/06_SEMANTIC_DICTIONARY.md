# Diccionario Semántico del Dominio

| Término | Significado |
|---|---|
| Asignatura | Agrupación académica superior que contiene temas |
| Tema | Unidad de conocimiento sobre la que se practica |
| Ejercicio | Definición reusable de una actividad evaluable |
| Opción | Alternativa de respuesta perteneciente a un ejercicio |
| Pista | Ayuda asociada a un ejercicio |
| Estudiante | Persona/personaje que realiza la práctica |
| Sesión de práctica | Intervalo lógico de interacción del estudiante con un tema |
| Intento | Evento real de resolución de un ejercicio |
| Respuesta | Contenido entregado por el estudiante para un intento |
| Progreso | Estado agregado actual del estudiante en un tema |
| Contexto de aprendizaje | Snapshot de variables observadas/calculadas usadas para decidir |
| Rendimiento | Clasificación resultante del procesamiento del contexto |
| Política de adaptación | Conjunto versionado de reglas que gobierna una estrategia |
| Regla de adaptación | Condiciones configuradas que producen una decisión |
| Evento de adaptación | Hecho que registra una decisión automática |
| Acción adaptativa | Cambio ejecutado como consecuencia de un evento |
| Catálogo | Definición genérica de una clasificación |
| Ítem de catálogo | Valor permitido dentro de un catálogo |
| Parámetro | Variable configurable cuyo valor modifica un escenario sin alterar estructura |
