# Acciones Adaptativas

- `SUBIR_DIFICULTAD`
- `MANTENER_DIFICULTAD`
- `BAJAR_DIFICULTAD`
- `ACTIVAR_PISTA`
- `CAMBIAR_TIPO_EJERCICIO`

Cada evento puede tener varias acciones en `ADP_ACCION_EVENTO`.

## Regla visual
El monitor adaptativo debe mostrar:
- contexto;
- nivel de rendimiento;
- acción;
- antes;
- después;
- motivo.
