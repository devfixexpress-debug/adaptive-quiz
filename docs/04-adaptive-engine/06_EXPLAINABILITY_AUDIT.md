# Explicabilidad y Auditoría

Toda decisión debe responder:
1. ¿Qué intentos influyeron?
2. ¿Qué métricas se calcularon?
3. ¿Qué política estaba vigente?
4. ¿Qué regla coincidió?
5. ¿Qué acción se ejecutó?
6. ¿Qué valor cambió?
7. ¿Cuándo ocurrió?

Cadena:
`PRA_INTENTO -> ADP_CONTEXTO_APRENDIZAJE -> ADP_EVENTO_ADAPTACION -> ADP_ACCION_EVENTO`.

Esto permite depurar comportamiento inesperado durante el reto técnico.
