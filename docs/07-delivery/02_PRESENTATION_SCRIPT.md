# Guion de presentación — 3 minutos

## 0:00–0:40 Problema
Las plataformas tradicionales tienden a presentar secuencias similares aun cuando los
estudiantes tienen rendimientos diferentes.

## 0:40–1:20 Solución
AdaptiveQuiz observa aciertos, errores y tiempos. Esa evidencia forma el contexto de
aprendizaje.

## 1:20–2:10 Pipeline
Mostrar:
`Contexto -> Procesamiento -> Decisión -> Adaptación`.

Explicar que ninguna pantalla permite seleccionar manualmente el nivel durante la demo.

## 2:10–2:40 Arquitectura
Separación entre captura, análisis, decisión, ejecución y UI. Backend modular y BD paramétrica.

## 2:40–3:00 Diferencial
Trazabilidad completa y evento adaptativo auditable. IA está prevista, pero el núcleo del Taller
es determinista y funciona sin ella.
