# Demo — 5 minutos

1. Abrir app y mostrar estudiante, tema y dificultad inicial INTERMEDIO.
2. Responder varias preguntas correctas rápidamente.
3. Abrir Monitor Adaptativo:
   - precisión;
   - tiempo promedio;
   - rendimiento;
   - regla;
   - INTERMEDIO -> AVANZADO.
4. Continuar con tres errores consecutivos.
5. Mostrar nueva decisión:
   - rendimiento BAJO;
   - AVANZADO -> INTERMEDIO;
   - pista activada.
6. Mostrar historial de eventos.
7. Abrir código:
   - Context builder;
   - Performance analyzer;
   - Adaptation engine;
   - executor.
8. Mostrar GitHub: commits, CI, README.
