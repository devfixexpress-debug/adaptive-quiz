## Base metodológica

- Tino Reyna Monteverde: arquitectura de datos con robustez semántica y estabilidad
  paramétrica; modelo funcional; eventos; parque de datos; catálogos y parámetros.
- Blaha/Rumbaugh: concepción, análisis de dominio, modelos de clases, estados e interacción.
- Manual de Modelamiento y Diseño de Base de Datos: modelo conceptual/lógico/físico,
  normalización, integridad y diccionario.
- Sommerville: ingeniería de requerimientos, arquitectura, OO/UML, pruebas, evolución,
  configuración y reutilización.
- Material de SI806 y Taller 001: software adaptativo y pipeline
  `CONTEXTO -> PROCESAMIENTO -> DECISIÓN -> ADAPTACIÓN`.
